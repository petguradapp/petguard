# PetGuard: Serverless Zero-Knowledge Pet QR Tag

A 100% serverless, zero-knowledge pet recovery web application hosted on GitHub Pages. Contact details are encrypted client-side using the native Web Crypto API (AES-GCM 256-bit).

- **No Backend / No Database:** Zero maintenance and $0 hosting costs.
- **Zero-Knowledge Privacy:** Ciphertext, IV, and cryptographic keys reside entirely inside the URL hash fragment (`#`), never leaving the client's device.
